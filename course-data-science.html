SYLLABUS & MODULES

Detailed Course Curriculum

A structured step-by-step roadmap designed to build your knowledge systematically from foundational concepts to advanced production deployments.

Module 01

Python for Data Science & Numeric Computing

Mastering the data science computing stack in Python.

Topics Covered:
  • • NumPy multidimensional arrays, indexing, slicing and vector operations
  • • Pandas DataFrames and Series: ingestion, filtering, grouping and aggregation
  • • Handling missing values, data imputation, deduplication and transformation
  • • Relational database querying with SQL and Python connectivity (SQLAlchemy)
Module 02

Exploratory Data Analysis (EDA) & Data Visualization

Discovering patterns, anomalies, and hypotheses through exploratory charting.

Topics Covered:
  • • Descriptive statistics: measures of central tendency, dispersion and skewness
  • • Univariate, bivariate and multivariate data exploration strategies
  • • Data visualization with Matplotlib, Seaborn: distributions, heatmaps, boxplots
  • • Feature correlation analysis, outlier detection and visual storytelling
Module 03

Statistical Foundations & Feature Engineering

Applying probability theory and mathematical feature preparation.

Topics Covered:
  • • Probability distributions (Normal, Binomial, Poisson) and Central Limit Theorem
  • • Hypothesis testing: t-tests, ANOVA, Chi-Square tests and p-value interpretation
  • • Feature scaling (MinMax, StandardScaler), encoding (One-Hot, Target)
  • • Feature selection techniques: Recursive Feature Elimination (RFE) and PCA
Module 04

Supervised Machine Learning Algorithms

Building predictive regression and classification models.

Topics Covered:
  • • Linear and Logistic Regression: mathematical intuition, training and coefficients
  • • Decision Trees, pruning and handling non-linear decision boundaries
  • • Ensemble learning: Random Forests, AdaBoost and Gradient Boosting (XGBoost)
  • • Support Vector Machines (SVM) and K-Nearest Neighbors (KNN)
Module 05

Model Evaluation, Validation & Hyperparameter Tuning

Rigorous validation ensuring models generalize reliably to unseen data.

Topics Covered:
  • • Overfitting vs. underfitting: Bias-Variance tradeoff
  • • Cross-validation strategies (K-Fold, Stratified K-Fold)
  • • Evaluation metrics: Precision, Recall, F1-Score, ROC-AUC, MAE, RMSE and R2
  • • Hyperparameter optimization with GridSearchCV and RandomizedSearchCV
Module 06

Unsupervised Learning, Deep Learning Overview & Capstone

Clustering, dimensionality reduction, neural networks and end-to-end project.

Topics Covered:
  • • K-Means clustering, hierarchical clustering and elbow method validation
  • • Dimensionality reduction with Principal Component Analysis (PCA)
  • • Introduction to Deep Learning: Artificial Neural Networks (ANN) basics
  • • End-to-end Capstone Project: from raw business data to trained model delivery
